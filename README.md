## ♟ Chess Game (C++ / Qt)

A graphical two-player chess game implemented in C++ using the Qt framework.  
The game allows two players to play locally on the same computer using a mouse-based graphical interface.

### Features
- Interactive 8×8 chessboard with graphical piece icons
- Turn-based gameplay with move validation
- Visual indication of the current player’s turn
- Win detection when a king is captured

### Technologies
- C++
- Qt (Qt Widgets, QPushButton, resource system)

### Notes
- Implements standard chess rules, excluding special moves such as castling and en passant
- Developed as a learning project to practice GUI programming, event handling, and object-oriented design

### What I Learned
- Designing a medium-sized C++ application using object-oriented principles
- Structuring code using classes and applying inheritance to model chess pieces
- Separating game logic from the graphical user interface
- Implementing move validation and turn-based game logic
- Managing application state efficiently during gameplay
- Developing event-driven graphical user interfaces with Qt
- Working with Qt resources and widget-based layouts
